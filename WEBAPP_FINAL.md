# 🎯 SOINTERA Web App - Готовое решение

## ✅ Что создано

### 1. Web App для консультаций
- **Файл**: `webapp/index.html`
- **Дизайн**: Компактный, в стиле Telegram
- **Функционал**: 3 типа консультаций с ценами
- **Интеграция**: Полная интеграция с Telegram Web App API

### 2. Express сервер
- **Файл**: `webapp/server.js`
- **Порт**: 3001
- **API**: REST API для консультаций
- **CORS**: Настроен для работы с Telegram

### 3. Интеграция с ботом
- **Команда `/consultations`**: Отправляет сообщение с кнопкой "Открыть"
- **Кнопка Web App**: Отображается в списке чатов как у BotFather
- **Скрипт отправки**: `src/scripts/send-webapp-message.ts`

## 🚀 Как запустить

### 1. Установка зависимостей
```bash
cd webapp
npm install
```

### 2. Запуск Web App
```bash
# Из корневой папки
npm run start:webapp

# Или для тестирования
npm run test:webapp
```

### 3. Настройка URL
Добавьте в `.env`:
```env
WEBAPP_URL=https://your-domain.com
```

### 4. Отправка сообщения с кнопкой
```bash
# Всем пользователям
npm run send:webapp

# Конкретному пользователю
npm run send:webapp 123456789
```

## 📱 Как это работает

1. **Пользователь пишет `/consultations`** боту
2. **Бот отправляет сообщение** с кнопкой "Открыть"
3. **Кнопка отображается** в списке чатов (как у BotFather)
4. **При нажатии** открывается Web App
5. **Пользователь выбирает** консультацию
6. **Данные передаются** в бот через Telegram API
