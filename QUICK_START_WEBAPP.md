# 🚀 Быстрый старт Web App

## 1. Запуск Web App
```bash
npm run start:webapp
```

## 2. Тестирование
```bash
npm run test:webapp
```

## 3. Отправка кнопки пользователям
```bash
npm run send:webapp
```

## 4. Настройка URL
В `.env` добавьте:
```env
WEBAPP_URL=https://your-domain.com
```

## 5. Команды бота
- `/start` - приветствие с кнопкой
- `/consultations` - сообщение с кнопкой Web App

## ✅ Готово!
Кнопка "Открыть" будет отображаться в списке чатов как у BotFather!
