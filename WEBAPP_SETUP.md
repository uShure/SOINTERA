# Настройка Web App для консультаций

## Описание

Web App создан для отображения кнопки "Открыть" в списке чатов Telegram бота, аналогично BotFather. При нажатии на кнопку открывается мини-приложение с функционалом записи на консультации.

## Структура файлов

```
webapp/
├── index.html          # Главная страница Web App
├── server.js           # Express сервер
├── package.json        # Зависимости Web App
└── README.md          # Документация
```

## Установка и запуск

### 1. Установка зависимостей Web App

```bash
cd webapp
npm install
```

### 2. Настройка переменных окружения

Добавьте в `.env` файл:

```env
# URL Web App (замените на ваш домен)
WEBAPP_URL=https://your-domain.com

# Порт для Web App сервера
WEBAPP_PORT=3001
```

### 3. Запуск Web App

```bash
# Из корневой папки проекта
npm run start:webapp

# Или для разработки
npm run dev:webapp
```

### 4. Настройка домена

1. Разместите Web App на вашем сервере
2. Убедитесь, что доступен по HTTPS
3. Обновите `WEBAPP_URL` в `.env`

## Использование

### Отправка сообщения с кнопкой Web App

```bash
# Отправить всем пользователям
npm run send:webapp

# Отправить конкретному пользователю
npm run send:webapp 123456789
```

### Команды бота

- `/start` - приветствие с кнопкой Web App
- `/consultations` - сообщение с кнопкой Web App для консультаций

## Дизайн

Web App выполнен в стиле Telegram:
- Использует CSS переменные Telegram для темизации
- Адаптивный дизайн для мобильных устройств
- Компактный интерфейс без лишних отступов
- Кнопки в стиле Telegram

## Функционал

1. **Три типа консультаций:**
   - Базовая (бесплатно)
   - Расширенная (2 000 ₽)
   - Премиум (5 000 ₽)

2. **Интеграция с Telegram:**
   - Отправка данных через `tg.sendData()`
   - Уведомления через `tg.showAlert()`
   - Автоматическое закрытие после выбора

3. **Связь с менеджером:**
   - Кнопка для связи с @natalylini
   - Автоматическая передача выбранной консультации

## Настройка для продакшена

1. **Домен и SSL:**
   - Настройте домен с SSL сертификатом
   - Обновите `WEBAPP_URL` в `.env`

2. **Мониторинг:**
   - Настройте логирование
   - Добавьте мониторинг ошибок

3. **Безопасность:**
   - Настройте CORS для вашего домена
   - Добавьте валидацию данных

## Тестирование

1. Запустите Web App локально
2. Используйте ngrok для тестирования:
   ```bash
   ngrok http 3001
   ```
3. Обновите `WEBAPP_URL` на ngrok URL
4. Отправьте тестовое сообщение боту

## Поддержка

При возникновении проблем:
1. Проверьте логи Web App сервера
2. Убедитесь, что URL доступен по HTTPS
3. Проверьте настройки CORS
4. Обратитесь к @natalylini
