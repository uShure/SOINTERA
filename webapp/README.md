# SOINTERA Web App - Консультации

Telegram Web App для записи на консультации, который отображается как кнопка "Открыть" в списке чатов бота.

## Особенности

- **Компактный дизайн** в стиле Telegram
- **Адаптивный интерфейс** для мобильных устройств
- **Три типа консультаций** с разными ценами
- **Интеграция с Telegram** через Web App API
- **Автоматическая передача данных** в бот

## Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера
```bash
npm start
```

### 3. Настройка URL
Обновите `WEBAPP_URL` в `.env` файле основного проекта:
```env
WEBAPP_URL=https://your-domain.com
```

## Структура

```
webapp/
├── index.html      # Главная страница с интерфейсом
├── server.js       # Express сервер
├── package.json    # Зависимости
└── README.md       # Документация
```

## API Endpoints

- `GET /` - Главная страница
- `GET /api/consultations` - Список консультаций
- `POST /api/consultation/request` - Заявка на консультацию

## Дизайн

Web App использует:
- CSS переменные Telegram для темизации
- Компактные отступы и размеры
- Адаптивную верстку
- Стили в духе Telegram

## Интеграция с ботом

1. Бот отправляет сообщение с кнопкой Web App
2. Пользователь нажимает "Открыть"
3. Открывается Web App с выбором консультаций
4. При выборе данные передаются в бот
5. Показывается уведомление с подтверждением

## Развертывание

1. Разместите файлы на сервере
2. Настройте HTTPS
3. Обновите `WEBAPP_URL` в боте
4. Протестируйте интеграцию
